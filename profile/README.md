programas a medida** que conectan con el ERP de nuestros clientes y sustituyen aplicaciones antiguas
(Visual Basic, Access…) por software moderno, fácil de instalar y de mantener.

## 📂 Nuestros proyectos

### 🌰 Recepción de almendra
**Clientes:** Frutos Secos Escrig · Frutos Secos Escrig, S.A. &nbsp;·&nbsp; 🔒 *repositorios privados*

Programa de escritorio para registrar las entradas de almendra de los agricultores: calcula el peso de
grano y el importe a partir de kilos, rendimiento y humedad, genera informes en PDF (lotes por silo,
parte diario, etiquetas…) y **exporta los albaranes de compra al ERP**, con simulación previa.
Sustituye a la antigua aplicación en Visual Basic 6 + Access. Se instala con un solo `setup.exe`.

`Python` `FastAPI` `React` `TypeScript` `SQLite` `SQL Server`

### 🚚 COTRABA2 · Gestión de portes
**Cliente:** COTRABA &nbsp;·&nbsp; 🔒 *repositorio privado*

Migración de la aplicación de portes de Visual Basic 6 + Access a un stack moderno: alta y consulta de
portes, búsqueda de clientes, proveedores y artículos del ERP, entrada masiva de precios y pesos,
informes en PDF y **exportación al ERP** con modo de prueba. Instalable con un solo `setup.exe`.

`Python` `FastAPI` `React` `TypeScript` `SQLite` `SQL Server`

### 🐄 Traspaso de recetas veterinarias
**Cliente:** Cooperativa Ganadera de Caspe &nbsp;·&nbsp; 🔒 *repositorio privado*

Proceso automático diario que envía las recetas veterinarias (piensos medicamentosos y medicamentos)
a los registros oficiales: **PresVet** (Ministerio de Agricultura) para las granjas de Aragón y **GTR**
(Generalitat de Catalunya) para las de Cataluña. Al terminar, manda un resumen por correo.

`Java` `SOAP` `REST` `MySQL`

### 🌐 Web corporativa oficomputer.com
**Cliente:** Oficomputer (proyecto propio) &nbsp;·&nbsp; 🔒 *repositorio privado*

Nuestra web en WordPress, con entorno de pruebas local en Docker y despliegue automático: cada cambio
pasa por revisión y comprobaciones antes de publicarse.

`PHP` `WordPress` `Docker` `GitHub Actions`
